# Communications Guide Index

## Use This Guide For

- email drafts
- replies
- meeting invites
- calendar changes
- family-facing or work-adjacent messaging

## Working Rules

- Prefer drafting over sending when tone matters.
- Use Google connectors for personal email drafts and invites where possible.
- Personal Gmail draft creation is allowed without asking first.
- Bot-owned mailbox sends must require the explicit confirmation keyword `CONFIRM SEND`.
- Keep tone calm, helpful, and low-ego.
- Escalate before sending anything sensitive, irreversible, or socially delicate.
